## tree-fold-jump

- [x] The tree palette needs fold/unfold and a jump to the
      next/last branch starting point. The user's words: "add
      shortcut to fold/unfold the tree, jump to the next/last
      branch starting point. The keybinding can reuse the fold mode
      keybinding in browse mode."
      Decision 2026-09-23: reuse the browse-mode fold arm exactly.
      `z` arms for the shared 3-second `SS_ARM_TTL`, the next
      character acts, like the browse `z` fold keys
      (docs/tui-turn-fold.md key table). The tree has no turn folds,
      so the second-key mapping is:

      | key | browse meaning | tree meaning |
      |---|---|---|
      | `za` | toggle the fold under the cursor | fold/unfold the innermost branch under the cursor |
      | `zo` | open the fold under the cursor | unfold that branch |
      | `zc` | close the fold under the cursor | fold that branch |
      | `zR` | open all folds | unfold every branch |
      | `zM` | close all folds | fold every branch, trunk rows stay |
      | `zj` | next fold | next branch starting point |
      | `zk` | last fold | last branch starting point before the cursor |
      | `zA` | toggle tool results in the turn | unbound in the tree, flashes |

      A branch starting point is a rewind marker row: the visible
      start of a branch block, one level below its target row. The
      request's "next/last" is wired as next/previous. `zk` lands on
      the branch start just before the cursor. An unbound second
      character flashes and drops the arm. It does not reach the
      fuzzy query. The tree starts fully expanded, as before. The
      `z` arm is opt-in folding on top of that.
      Shipped 2026-09-23: `SessionTree` gained `parent_of`,
      `has_children`, `is_marker`, and `foldable_seqs` in
      `bin/tui/src/palette/tree_model.rs`. `App` gained
      `tree_folded` (the folded branch-point seqs, reapplied over
      the frame expand-all) and `tree_z_arm`, plus
      `tree_fold_key`, `tree_fold_target`, and `apply_tree_folds`
      in `bin/tui/src/app.rs`. `z` and an armed second character
      route through the tree-stage key table in `App::press`.
      Fold state resets with the tree view on a session switch or a
      new tree visit, like the view state.
      Tests: `tree_fold_tests` in `bin/tui/src/app.rs`
      (`tree_stage_starts_fully_expanded`,
      `zc_folds_the_branch_under_the_cursor`,
      `zm_zr_fold_all_branches`,
      `zj_zk_jump_between_branch_starts`,
      `fold_state_resets_on_session_switch`,
      `unbound_fold_keys_do_not_reach_the_query`).
